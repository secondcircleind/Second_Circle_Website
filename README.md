# Second Circle India Website

React/Vite website for Second Circle India. The production target is static deployment from GitHub to Hostinger.

## Development

```powershell
npm run dev
npm run build
npm run preview
```

The production build is generated in `dist/`. Do not commit `dist/`, `node_modules/`, environment files, logs, or secrets. Hostinger should serve the built files with the included Apache fallback configuration.
